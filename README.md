# 📊 Sistema de Gestión Software FJ - Fase 4 Programación (UNAD)

## 📌 Descripción del proyecto

Este proyecto implementa un sistema de gestión para la empresa ficticia **Software FJ**, desarrollado en Python bajo el paradigma de **Programación Orientada a Objetos (POO)**.

El sistema permite administrar clientes, servicios y reservas, aplicando manejo avanzado de excepciones y simulaciones de operaciones reales.

---

## 🧠 Funcionalidades principales

- Registro y validación de clientes
- Gestión de servicios:
  - Reserva de salas
  - Alquiler de equipos
  - Asesoría especializada
- Creación y manejo de reservas
- Estados de reservas: Pendiente, Procesada, Confirmada, Cancelada
- Manejo de errores personalizado
- Registro de eventos en logs

---

## 🏗️ Tecnologías usadas

- Python 3
- Programación Orientada a Objetos
- Manejo de excepciones
- Archivos de texto (logs)
